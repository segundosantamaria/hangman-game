# Hangman Game

A command-line Hangman game written in Python. The computer picks a random word and the player guesses it one letter at a time before running out of lives.

## How to run

1. Make sure you have Python 3 installed.
2. Download or clone this repository.
3. The final version of the game is in the `task` folder. Run it with:

   python task/main.py

## How it works

- A random word is chosen from a list of words.
- The player guesses one letter per turn.
- Correct guesses are revealed in the word; wrong guesses cost a life.
- The game ends when the word is completed or the lives run out.
